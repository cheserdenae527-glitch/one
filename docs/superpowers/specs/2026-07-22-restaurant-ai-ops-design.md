# 餐饮AI运营助手 —— 产品设计规格书

> 版本：v1.0
> 日期：2026-07-22
> 状态：设计稿

---

## 一、产品定位

**一句话：** 让不懂运营的餐饮老板，每天花 5 分钟就能把大众点评/小红书/抖音做好。

**目标用户：** 大陆中小餐饮商家（街边店、夫妻店、小型连锁）
- 年营收 50-300 万，老板就是厨师/店长
- 知道大众点评重要，但没有时间/能力运营
- 想发小红书/抖音，但不会写文案、做图
- 愿意为"省时间"付费，每月 99-199 元能接受

**核心价值主张：** 你不是缺好手艺，是缺一个人帮你把店搬到网上。

## 二、整体架构

产品分为三层：

```
┌─────────────────────────────────────────────────┐
│                运营规划层                         │
│  账号创建 · 昵称/头图/背景 · 周计划 · 月计划     │
│  账号阶段策略 · 创作方向规划                     │
├─────────────────────────────────────────────────┤
│                  执行层                          │
│  ┌────────┬────────┬────────┬────────┐          │
│  │内容创作 │图片生成 │视频生成 │评价管理 │         │
│  └────────┴────────┴────────┴────────┘          │
├─────────────────────────────────────────────────┤
│                 数据底座                         │
│  热门榜单库 · 人设模板库 · 用户链接库 · 商家信息库│
└─────────────────────────────────────────────────┘
```

**右侧栏（所有页面常驻）：**
- 热门内容参考面板（260px 宽）
- 创作方向建议
- 手动粘贴链接入口

## 三、用户注册与进门流程

### Step 1 — 账号注册
- 邮箱/手机号注册 + 登录（Supabase Auth）
- 14 天试用倒计时开始

### Step 2 — 填写店铺信息
**必填：** 店名、地址、电话、菜系、客单价范围、目标客群
**选填：** 各平台链接（大众点评/小红书/抖音）
**品牌视觉素材（选填）：**
- 店铺 Logo
- 门头/店内环境照片
- 特色花纹/设计元素
- 菜品成品图
  → 存入商家信息库，后续图片/视频生成时作为风格参考

### Step 3 — AI 人设选择
- 根据店铺信息，AI 从热门数据库中提取匹配的成功模式
- 展示 2-3 套预设人设供用户选择
- 每套人设含：定位句、语气风格、内容方向示例
- 示例：
  > **方案 A：老字号口碑路线**
  > 语气：朴实真诚，突出"做了 XX 年"
  > 内容方向：后厨纪实 → 老客故事 → 经典菜品
  >
  > **方案 B：年轻人打卡路线**
  > 语气：活泼潮流，带网络感
  > 内容方向：环境氛围 → 网红单品 → 社交场景
- 用户也可选"自定义"，后续随时修改

### Step 4 — 进入 Dashboard
- 自动生成第一周运营建议
- 右侧热门参考栏已就绪
- 引导用户进行第一次内容创作

## 四、运营规划层

### 4.1 账号总览
- 三大平台各一张卡片（大众点评 / 小红书 / 抖音）
- 每张卡片显示：账号昵称、头像、粉丝量（有链接时可展示）、最近更新状态
- 未绑定的平台显示"去创建"引导按钮

### 4.2 账号阶段指引
- AI 根据店铺信息判断当前阶段，给出策略建议：
  - **新建期（0-1 月）：** 搭建基础、积累首批评价/笔记
  - **成长期（1-3 月）：** 增加发布频率、追热点、做活动
  - **成熟期（3 月+）：** 维护口碑、老客召回、品牌深化
- 每个阶段有具体的行动建议和内容方向

### 4.3 内容日历（周计划/月计划）
- **视图：** 月历格式展示，有内容的日期显示当天标题
- **内容类型：** 点评笔记、小红书、抖音、评价回复、促销活动等
- **颜色区分：** 不同平台用不同颜色标记
- **交互：** 点击日期展开详细计划，可"一键生成内容"跳转到内容创作模块
- **自动排期：** AI 根据人设+阶段+热点自动填充计划，用户可手动编辑

### 4.4 创作方向建议
- 显示在右侧栏（与热门参考共用侧栏区域）
- 基于当前热门趋势 + 店铺人设，推荐具体内容主题
- 来源：模板引擎分析热榜后得出的趋势结论

## 五、内容创作模块

### 5.1 三门入口
```
┌─────────────────────────────────────────────┐
│  ✍️ 文案创作    🎨 图片生成    🎬 视频生成    │
│                                             │
│  粘贴链接，一键复刻                          │
│  [粘贴大众点评/小红书/抖音链接...]            │
│  [一键复刻]                                  │
└─────────────────────────────────────────────┘
```

### 5.2 文案创作流程
1. 选择内容类型（点评简介 / 小红书笔记 / 评价回复 / 促销活动...）
2. 选择参考来源：右侧热门内容选中 或 粘贴链接
3. 调整参数：语气（轻松/正式/活泼）、长度（短/中/长）
4. 点击生成 → AI 生成草稿（可编辑） → 保存 / 再生成 / 去发布
5. 每次生成的关联元数据：参考来源、人设信息、生成时间

**大众点评文案五大类（详见附录）：**
- 店铺基础建设（简介、标签、搜索关键词）
- 转化页面（菜品标题、菜品描述、套餐包装）
- 内容运营（动态发布、新品推广、活动策划）
- 用户互动（好评回复、差评处理、评价引导）
- 营销活动（节日活动、新客活动、老客召回）

### 5.3 图片生成流程
1. 选择预设样式模板（菜品展示 / 海报 / 封面 / 环境图 / 菜单图 / 活动图）
2. 每个模板有 2-3 个风格变体（白底精拍风 / 餐桌实拍风 / 手绘插画风）
3. **预设样式需提供示例图供用户预览**
4. 选择目标平台 → 自动匹配尺寸和构图比例：
   - 大众点评：1:1 方图
   - 小红书：3:4 竖图
   - 抖音：9:16 视频封面
   - 用户也可手动选择其他比例
5. 内容设置：选择展示菜品、叠加文字（如"招牌必点"）
6. **图片上的文字和文字样式可直接编辑调整**
7. **所有操作即时响应，无需过多等待**
8. AI 生成 **多张候选图供用户选择**
9. 保存到素材库，支持批量下载

### 5.4 视频生成流程
**路线 A：复刻参考视频**
1. 用户粘贴抖音/小红书视频链接
2. AI 拆解视频脚本（结构、旁白、镜头、BGM 风格）
3. AI 根据商家信息改写脚本（店名、菜品、场景替换）
4. **支持用户上传参考图片，生成时贴合门店真实环境**
5. 调用火山引擎生成视频

**路线 B：从模板创建**
1. 选择视频类型模板（菜品展示 / 后厨纪实 / 探店打卡 / 活动预告 / 新品发布）
2. **可从运营规划日历的文案直接跳转，自动选择对应类型的脚本模板**
3. 平台自动匹配尺寸（抖音 9:16、小红书 3:4、视频号 16:9）
4. 脚本预览（可编辑）
5. 根据商家图片素材生成视频

## 六、热门内容侧栏

### 6.1 服务端总榜单
- 每天凌晨定时爬取各平台（大众点评/小红书/抖音）餐饮类热门内容
- 范围控制：全平台餐饮类 TOP 内容，按菜系和城市做一级分类
- 用户打开即看到，无需任何操作

### 6.2 侧栏交互
- **筛选：** 平台（点评/小红书/抖音）、菜系、城市
- **列表展示：** 每项含封面缩略图、标题、店铺名、点赞数、菜系标签
- **选中参考：** 点击某条内容 → 左侧创作区域会展示该内容详情
- **"参考撰写"：** 参考该内容的语言风格，生成提示词模板；附带图片用视觉模型理解后生成提示词；视频拆解脚本适配后重新生成

### 6.3 用户手动输入
- 侧栏底部始终有"粘贴参考链接"入口
- 粘贴后 AI 分析：提取标题、点赞数、店铺信息、关键词
- 存入用户自己的链接库，下次打开还在

## 七、评价管理模块

### 7.1 评价概览
- 按评分分级：好评 / 中评 / 差评
- 待回复评价列表

### 7.2 AI 回复
- **去 AI 味三层策略：**
  1. 强制注入评价原文的具体细节（非模板化）
  2. 品牌人设决定回复语气（老字号朴实 / 打卡店活泼）
  3. 结构性随机化（句子长度、开头方式、emoji 使用随机组合）
- 同一家店不同评价的回复，读起来像不同员工写的
- 回复策略按评分：
  - 4-5 星：感谢 + 推荐招牌菜 + 欢迎再来
  - 3 星：感谢建议 + 解释改进 + 邀请再次光临
  - 1-2 星：诚恳道歉 + 具体改进方案 + 引导私信

### 7.3 评价引导
- 生成"引导好评"话术：打印小票二维码、结账时口播引导

## 八、模板引擎（核心差异化引擎）

### 8.1 模板数据结构

**切入角度模板：**
```json
{
  "id": "tpl_angle_017",
  "type": "angle",
  "name": "横评对比",
  "desc": "同品类对比多家店，突出自家优势",
  "hook": "问题式",
  "tone": ["专业评测", "本地人视角", "体验派"],
  "structure": ["钩子（问题引发好奇）", "逐店对比", "总结推荐"],
  "cuisines": ["火锅", "烧烤"],
  "platforms": ["大众点评", "小红书"],
  "weight": 0.82,
  "used": 127,
  "source": "热榜分析"
}
```

**体裁模板：** 测评体、故事体、攻略体、合集体、对比体、揭秘体、教程体、话题体

### 8.2 提取流水线
1. **每日定时触发：** 读取当日热门榜单内容，每批 20 篇
2. **LLM 逐篇分析：** 提取切入角度、体裁、结构框架、钩子方式、语气特征、适用菜系
3. **去重与聚类：** 同角度合并，保留表现最好的（点赞数最高）
4. **存入模板库：** 初始权重 = 该内容点赞数 / 同类最高赞（标准化到 0-1）

**覆盖量预估：** 初期 20-30 个切入角度 × 6-8 个体裁 ≈ 200+ 种组合，一个商家每周 3-5 篇，可 3-6 个月不重复

### 8.3 匹配算法（四层漏斗）
1. **第一层：** 菜系 + 平台匹配 → 排除不相关模板
2. **第二层：** 排除近 5 篇用过的角度 → 避免重复
3. **第三层：** 按人设筛选匹配的语气方向
4. **第四层：** 加权随机排序（高权重更可能选中，但保证多样性）

**输出：** 3 个候选（角度和体裁均不同）

### 8.4 反馈进化系统
| 用户行为 | 权重变化 |
|---------|---------|
| 保存草稿 | +1 |
| 发布上线 | +3 |
| 手动编辑后发布 | +2 |
| 点击重新生成 | -1 |
| 连续 3 次重新生成 | 标记"不推荐" |

**淘汰机制（每周扫描）：**
- 权重 < 0.1 → 删除
- 30 天未使用 → 标记休眠
- 被标记"不推荐"5 次以上 → 删除
- 所有删除保留日志，可恢复

### 8.5 创新机制
- **组合变异：** 每月一次，两个高权重角度合并 → 新角度
- **热点注入：** 平台新热点话题 → 自动生成临时模板
- **编辑模式学习：** 用户多次手动修改模式 → 生成变体
- **节日模板：** 结合季节/节日自动生成

### 8.6 同质化对抗策略
1. **人设引擎** — 不同菜系/价位/位置的人设天然不同
2. **强制个性化数据注入** — 每次生成强制加入店铺独有信息
3. **参考内容分散** — 用户选不同参考内容，输出自然不同
4. **人工编辑环节** — 所有生成内容为草稿状态，用户可修改
5. **同质化检测** — 系统内跑相似度检测，雷同时自动调整参数

## 十、需要避免的坑

### 评价回复的"AI味"
- 三层次去 AI 味：细节注入 → 人设决定语气 → 结构性随机化
- 不做模板化回复，"感谢您的支持，欢迎下次光临"这种不如不回

### 内容同质化
- 不同商家即使信息雷同，也要通过"多维切入角度"制造差异
- 核心思路：不是"找不同"，而是"造角度"
- 系统要有同质化检测 + 主动切换机制

### 平台反爬
- 总榜单：服务端定时爬取，频率低、范围可控
- 城市级/具体数据：用户手动粘贴链接，零反爬风险

## 附录：大众点评文案体系

大众点评本质上是一个"用户决策平台"，文案目标是：**提高搜索点击 → 提高进店率 → 提高成交 → 提高复购**。分为五大类 Agent：

```
大众点评运营Agent
├── 店铺诊断
│   ├── 简介优化（3秒建立第一印象）
│   ├── 标签优化（场景/人群/特色标签）
│   └── 搜索关键词优化（火锅、生日聚餐等搜索词布局）
├── 商品文案Agent
│   ├── 菜品标题优化（老坛酸汤招牌土鸡 > 招牌鸡）
│   ├── 菜品描述（食材来源+制作方式+口感体验+消费场景）
│   └── 套餐包装（标题+卖点+详情）
├── 内容运营Agent
│   ├── 日常动态发布
│   ├── 新品推广
│   └── 活动策划
├── 评论运营Agent
│   ├── 好评回复
│   ├── 差评处理
│   └── 评论引导
└── 营销Agent
    ├── 节日活动
    ├── 新客活动
    └── 老客召回
```
